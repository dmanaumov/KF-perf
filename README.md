# КФ Performance

Портал управления продвижением КонтентФермы: реклама (Яндекс Директ, Google Ads, VK Реклама, Instagram/Meta, Telegram Ads, Авито, 2ГИС, Яндекс Бизнес, Ozon, WB), SEO и GEO (видимость в AI-ассистентах). Кабинет команды + кабинет клиента по секретной ссылке.

Стек как у остальных сервисов КФ: Node 20 + Express + Postgres 16, фронт без сборки (vanilla JS, SVG-графики), фирменный стиль kontentferma.com (Manrope, `#004643`, `#ff5f60`). Вход команды — логином Mattermost.

## Что умеет

**Обзор (руководитель):** расход месяца против плана с отметкой «где должны быть сегодня», лиды, CPL; расход по дням за 30 дней; лента сигналов; таблица всех проектов: каналы, расход/план, прогноз (пейсинг), лиды/план, CPL против цели, SEO ТОП-10, GEO-видимость, задачи и просрочки.

**Проект:**
- *Сводка* — KPI за период с дельтой к прошлому периоду, динамика (расход / лиды / CPL с линиями плана и цели), план месяца с прогнозом, каналы, сигналы, трафик сайта по источникам из Метрики.
- *Кампании* — таблица кампаний всех каналов с сортировкой и фильтром.
- *Задачи* — канбан (бэклог → к работе → в работе → на проверке → готово), направления (реклама/SEO/GEO/аналитика/креативы), гипотезы с результатом, флаг «видно клиенту».
- *SEO* — позиции в Яндексе (Yandex Search API, раз в сутки), Google через CSV, ТОП-3/10/30, изменение за неделю, спарклайны, органический трафик из Метрики.
- *GEO / AI* — промпты клиентов прогоняются через ChatGPT, Perplexity, Gemini, Claude, DeepSeek, YandexGPT; считаются видимость бренда, доля голоса против конкурентов, цитирование сайта, место среди брендов; матрица «промпт × движок» с полным ответом; домены, которые AI цитирует (куда публиковаться); трафик из AI-сервисов по Метрике.
- *Журнал* — что меняли и когда (видно клиенту или только команде).
- *Каналы и данные* — подключение кабинетов, проверка доступа, ручное обновление, CSV-импорт и ввод по дням для площадок без API, история синхронизаций.
- *План* — бюджет / лиды / целевой CPL / выручка на месяц, по проекту и по каналам.

**Сигналы** (считаются на лету): перерасход/недорасход по прогнозу, CPL выше цели на 20%+, 3 дня без лидов при расходе, ошибки синхронизации, устаревшие ручные данные, просроченные задачи, выпадение запросов из ТОП-10.

**Кабинет клиента** `/c/<token>`: KPI, план/факт, каналы, SEO, GEO, «что делаем сейчас», «сделано», журнал. Ссылку можно отключить или перевыпустить.

**Роли:** администратор (всё + роли), руководитель (все проекты), специалист (только свои проекты: менеджер или участник). Админы — из `ADMIN_EMAILS`/`ADMIN_LOGINS`; если список пуст, админом становится первый вошедший.

## Источники данных

| Площадка | Как | Что нужно |
|---|---|---|
| Яндекс Директ | Reports API v5 | OAuth-токен `direct:api`, Client-Login для агентского; ID целей (опц.) |
| Яндекс Метрика | Stat API | OAuth `metrika:read`, номер счётчика; ID целей |
| Google Ads | REST searchStream | env: developer token, OAuth client; на канал: refresh token, customer id |
| VK Реклама | ads.vk.com API v2 | токен клиента/агентства |
| Instagram / Meta | Marketing API insights | System User token `ads_read`, ad account id |
| Telegram Ads, Авито, 2ГИС, Я.Бизнес, Ozon, WB | CSV / ввод по дням | — |
| SEO Яндекс | Yandex Search API | `YANDEX_SEARCH_API_KEY`, `YANDEX_SEARCH_FOLDER_ID` |
| GEO | API AI-движков | ключи в env, каждый движок опционален |

Токены кабинетов хранятся в БД зашифрованными (AES-256-GCM, ключ из `APP_SECRET`).
Синхронизация рекламы перезаписывает последние 7 дней (конверсии «доезжают»), первая загрузка — 90 дней.

## Запуск

```bash
cp .env.example .env   # заполнить POSTGRES_PASSWORD, APP_SECRET, MATTERMOST_URL, ADMIN_EMAILS
docker compose up -d --build
```

Dokploy: Compose-проект из репозитория, домен на сервис `app` порт `3000`, переменные — во вкладке Environment.
Чтобы показать портал до подключения кабинетов — `SEED_DEMO=true` на первом старте (заливает 4 демо-проекта в пустую БД), потом выключить и удалить демо-проекты.

Локально без Docker: `npm ci && DATABASE_URL=... APP_SECRET=... LOCAL_ADMIN_PASSWORD=... npm start`.

### Автоматизация

Встроенный планировщик каждые 10 минут проверяет, что пора обновить (интервалы в env). Альтернатива/дополнение — n8n:

```
POST /api/cron/sync   X-Api-Key: $AUTOMATION_API_KEY   # реклама + Метрика
POST /api/cron/seo                                      # позиции
POST /api/cron/geo                                      # AI-видимость
```

## Структура

```
src/
  server.js          Express, статика, роуты
  config.js          все настройки из env
  db.js              схема Postgres (создаётся на старте)
  auth.js            вход через Mattermost, сессии, роли, доступ к проектам
  platforms.js       каталог площадок, AI-рефереры, статусы
  connectors/        Директ, Метрика, Google Ads, VK Ads, Meta
  sync.js            синхронизация, CSV-импорт
  metrics.js         сводки, пейсинг, сигналы, SEO/GEO-агрегаты
  seo.js, geo.js     съём позиций и AI-проверки
  scheduler.js       встроенный планировщик
  seed.js            демо-данные
  routes/            team (API команды), client (кабинет клиента), cron
public/              index.html + app.js (команда), client.html + client.js, charts.js, app.css
```
